## Questions Worth Asking

Every question costs the user time. Before asking one:

- **Never ask what the agent can find out.** Research it, or send a background agent to.
- **Check earlier rulings first.** When one of the user's rulings answers it, apply it silently (see
  "Check earlier rulings first" in agent-conduct's "Respect the User's Time" memory).
- **Ask only what matters.** A question is worth asking when a wrong answer would waste a lot of
  work or be hard to undo.
- **Otherwise, guess.** For low-to-mid impact items, a guess the user can easily undo beats a
  question. Say what was guessed, so the user can reverse it.
- **Batch them.** Ask every question at once, numbered, each with the agent's best guess, so the
  user can answer "all fine except 2". Say that any left unanswered will be guessed, and list those
  guesses in the report.

# Writing Model Notes

> **EXPERIMENTAL.** Part of an unfinished recipe.

Each file in this folder holds what was learned about one model family. Notes are kept per
version, because a new version can behave differently with the same prompt: a section heading
names the exact model ID, and a note about a newer version goes in a new section rather than
replacing the old one.

Every note says what kind of task it was learned on and how many items it rests on, so a reader
can judge how far it carries. Prices change; each price carries the date it was read.

The numbers in these files come from one experiment unless a section says otherwise: a yes/no
decision about short text items, scored against 35 items one person decided (20 used for tuning,
15 held out), each final prompt run 3 times, with a confidence threshold of 75.
